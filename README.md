# VoiceLab · двусторонний голосовой режим

.NET 10, статический интерфейс и SignalR. Все движки работают локально.

[Архитектура](docs/ARCHITECTURE.md) · [Инструкции для сопровождения](docs/HANDOFF.md) · [PNG-схема](docs/architecture.png)

## Запуск

На ПК, где модели уже загружены в соседнюю папку models, откройте PowerShell в папке VoiceLab и выполните:

```powershell
pwsh -File ./start-local.ps1
```

Для другой папки передайте -Models. На чистой машине сначала установите .NET 10 SDK, Python 3.13 x64 и драйвер NVIDIA, затем в отдельном окружении установите зависимости и загрузите модели:

```powershell
python -m pip install "sherpa-onnx==2.0.1" "piper-tts==1.8.0" "onnx>=1.17" "vosk==0.3.45"
python setup_models.py
pwsh -File ./start-local.ps1
```

Откройте http://127.0.0.1:5188, нажмите «Микрофон» и разрешите захват. После первого прогрева надпись «Микрофон активен» означает, что можно говорить. Микрофон остаётся активен во время ответа и между репликами. Для теста при включённой акустике браузер запрашивает echoCancellation и noiseSuppression. Можно сравнить с гарнитурой.

## Языки разговора

| Код | Язык | STT | Голос Piper |
| --- | --- | --- | --- |
| ru | Русский | T-one | Dmitri, Irina |
| en | English | Vosk Small US | Lessac |
| de | Deutsch | Vosk Small DE | Thorsten |
| fr | Français | Vosk Small FR | Siwis |
| tl | Filipino / Tagalog | Vosk TL PH Generic | Filipino Medium |

В шапке также доступен выбор голоса для активного языка. Предпочтение сохраняется отдельно для каждого языка и применяется со следующего ответа или повторного синтеза.

Язык можно выбрать в шапке вручную или попросить об этом на текущем языке. Пример: «Давай перейдём на английский». LLM отдаёт управляющий маркер @LANG:en. Сервер скрывает маркер, озвучивает короткое подтверждение целевым голосом и передаёт код в браузер для переключения STT и следующих ответов. Для возврата к языку из настроек используйте команду «Вернёмся к исходному языку» (маркер @LANG:home) или кнопку «Исходный язык». Управляющий протокол добавляется к пользовательскому промпту. В пользовательском промпте доступны {{language}} и {{home_language}}.

«Сбросить диалог» останавливает текущий ответ, очищает историю, записи и замеры, возвращает исходный язык. Открытый микрофон остаётся открыт. Переход на новый язык прогревает STT один раз за сеанс микрофона. После переключения начните говорить, когда индикатор снова покажет «Микрофон активен».

Модели Vosk и Piper для Filipino / Tagalog распространяются по CC BY-NC-SA 4.0. Веса загружаются отдельно.

## Голоса OmniVoice

Для установки на Windows с NVIDIA и FFmpeg выполните **pwsh -File ./setup-omnivoice.ps1** перед **start-local.ps1**. Скрипт создаёт отдельное окружение CUDA PyTorch и скачивает веса OmniVoice. При наличии модели стартовый скрипт запускает сервис на 127.0.0.1:5194.

В шапке VoiceLab нажмите **Создать голос**, укажите имя, аудио и точную расшифровку. Лучше использовать 3–10 секунд чистой речи. Интерфейс принимает до 30 секунд и 10 МиБ. Созданный голос выбирается автоматически. Можно нажать **Прослушать пробу** или использовать голос в обычном разговоре. Служба хранит закодированные профили рядом с моделями в voice-profiles. Исходный аудиофайл не сохраняется.

Настройка «Скорость OmniVoice» в меню создания голоса влияет на пробу и следующие реплики. По умолчанию 8 шагов диффузии, доступны 12 и 16. Меньшее число шагов может изменить звучание.

OmniVoice возвращает готовый PCM для отдельного фрагмента. VoiceLab подаёт фрагменты по мере генерации LLM. Перебивание останавливает воспроизведение и отменяет дальнейшие запросы. Уже запущенный GPU-вызов может завершиться в фоне.

## Как работает перебивание

- Микрофон захватывается через AudioWorklet. После обнаружения речи 40-мс PCM-кадры с коротким preroll передаются по одному открытому клиентскому потоку SignalR. Выбранный онлайн-движок сохраняет состояние декодирования и публикует изменившиеся частичные гипотезы.
- Два одинаковых начальных слова в двух последовательных гипотезах прерывают запланированное воспроизведение и отменяют SSE и TTS запроса. Короткая фраза может прервать ответ своей финальной гипотезой. Финализация запускается по настроенной тишине, по умолчанию 160 мс. Подавление эха и стабильность префикса уменьшают вероятность реакции на звук динамиков.
- LLM публикует токены по SSE через llama.cpp. Короткий первый фрагмент отправляется в Piper ещё во время генерации. Декодер Piper отдаёт настоящий PCM до завершения синтеза всего фрагмента. Аудио воспроизводится по мере получения. Первая фраза передаётся по границе пунктуации или слова, чтобы избежать разрезания слов.
- Кэш TTS использует RAM (2 минуты), затем диск (5 часов), затем ONNX. Повторный синтез обходит кэш. Запись исходного микрофона и синтезированные фрагменты можно переиграть по клику на реплику. История и записи хранятся в текущей вкладке.

## Движки и замеры

| Этап | Движок |
| --- | --- |
| STT | sherpa-onnx / T-one Russian CTC на CPU, 8 кГц внутри модели |
| LLM | llama.cpp / Qwen3-1.7B Q4_K_M, CUDA, thinking выключен |
| TTS | Piper Dmitri Medium, разделённые ONNX encoder и decoder на CPU, 22050 Гц |
| Транспорт | SignalR upload и события поверх WebSocket, SSE от LLM, поток PCM от TTS |

Одиночный прогретый прогон на RTX 5080 с официальным речевым WAV, PCM подавался с реальной скоростью, с добавленной паузой перед финализацией. Первый непустой STT partial появился через 1042 мс от старта аудио. STT final пришёл через 33 мс после команды финализации. Первый видимый токен LLM — 111 мс. Первый PCM-фрагмент TTS — 35 мс после запроса синтеза первого фрагмента. От последнего VAD-положительного блока до первого PCM у клиента — 406 мс. Подтверждение отмены в отдельном запросе — 3 мс. В другом прогоне подтверждение заняло 32 мс.

Waterfall разделяет STT partial, VAD, STT final, первый видимый токен LLM, первый PCM TTS и запланированное начало Web Audio. «Голос → звук» — оценка от последней детекции речи до запланированного звука. Физическую аудиозадержку нужно измерять loopback. Числа одиночного прогона не являются p95 или гарантией. Холодный запуск CUDA может занять десятки секунд. Для SLA требуется серия живых реплик и измерение p95 на прогретом тракте.

## Langfuse

Загрузка текстового промпта из локального Langfuse доступна по имени и метке. Приложение использует LANGFUSE_PUBLIC_KEY и LANGFUSE_SECRET_KEY на сервере и подставляет переменные {{name}} из JSON в редакторе. Langfuse не требуется для живого контура. Вызовы tools, экспорт трасс и адаптеры OpenAI Realtime в эту сборку не входят.
